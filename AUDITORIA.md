# Auditoría del sitio: El Tradicional

## Elementos positivos

- Estructura clara: inicio, catálogo, historia y ubicación.
- Diseño visual coherente con una panadería: colores, tipografías e imágenes atractivas.
- Adaptación prevista para computadora, tablet y celular.
- Catálogo con categorías, precios, descripciones y botones para pedir.
- Enlaces directos a WhatsApp, teléfono, mapa y redes sociales.
- Buen uso de textos alternativos y enlace para saltar al contenido.

## Aspectos por mejorar

- Datos de prueba: reemplazarlos por el teléfono, dominio, Instagram, dirección y fecha reales.
- Imágenes repetidas o poco representativas: usar fotografías reales y autorizadas de cada producto.
- Navegación en celular: añadir un menú desplegable accesible para ahorrar espacio.
- Filtros del catálogo: mostrar claramente la categoría activa y los productos disponibles.
- CSS antiguo y repetido: eliminar reglas innecesarias y ordenar los estilos.
- Estado “Abierto hoy”: actualizarlo según los horarios reales y días festivos.
- Dependencia de servicios externos: guardar recursos importantes localmente o tener alternativas.
- SEO y redes sociales: agregar una imagen de vista previa y completar la URL real.

## Prioridad

1. Corregir todos los datos provisionales.
2. Cambiar o verificar las imágenes.
3. Mejorar el menú y los filtros en celular.
4. Ordenar el CSS y revisar el SEO.
