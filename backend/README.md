# Backend de El Tradicional

API REST en Node.js + Express, con Prisma sobre la base de Supabase que ya
existe (no crea ni cambia tablas). Se despliega en Render como Web Service.

Se arma en la Fase 4 del proyecto final. Hasta que este desplegado y tenga
`DATABASE_URL`, el sitio (`frontend/`) sigue usando la Edge Function
`supabase/functions/api`.
